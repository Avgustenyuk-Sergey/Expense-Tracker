---

## Описание

Программа Expense Tracker — это графическое приложение для учета личных расходов.

Позволяет:
- Добавлять расходы
- Фильтровать по категории и дате
- Считать сумму расходов
- Сохранять и загружать данные из JSON

---

## Требования

- Python 3.10+
- Установленная библиотека tkinter

---

## Как использовать

1.Запустите программу:

python main.py

2.Введите данные:

Сумма (положительное число)
Категория (например: еда, транспорт)
Дата (в формате DD/MM/YYYY)
Нажмите "Добавить расход"

3.Для фильтрации:

Введите категорию (необязательно)
Укажите диапазон дат (необязательно)
Нажмите "Фильтровать"

4.Для подсчёта:

Нажмите "Сумма за период"

5.Для удаления:

Выберите запись в таблице
Нажмите "Удалить выбранный"

## Тестирование

Позитивный случай:

Ввод: 100, транспорт, 10/05/2026
Результат: запись успешно добавлена

Негативный случай:

Ввод: abc вместо суммы
Результат: ошибка "Сумма должна быть положительным числом"

Граничный случай:

Ввод: 0
Результат: ошибка
Ввод: 0.01
Результат: успешно

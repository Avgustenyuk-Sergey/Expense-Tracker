**Автор:** Августенюк Сергей

**Дата:** 05.05.2026  

---

## Описание

Программа Expense Tracker — это графическое приложение для учета личных расходов.

Позволяет:
- Добавлять расходы
- Фильтровать по категории и дате
- Считать сумму расходов
- Сохранять и загружать данные из JSON

---

## Требования

- Python 3.10+
- Установленная библиотека tkinter
